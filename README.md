# عيادة الدكتور عبد الكريم عليوي
> بورد طب الأطفال وحديثي الولادة

تطبيق ويب متكامل لإدارة العيادة الطبية، يشمل متابعة الأطفال، الزيارات، القياسات، الفحص السريري، المرفقات الطبية، والوصفات الطبية الإلكترونية والمصورة والطباعة.

---

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية**: Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons.
- **إمكانية الوصول والاتجاه**: لغة عربية كاملة، اتجاه من اليمين إلى اليسار (RTL)، خط عربي حديث ومحسن للقراءة الطبية.
- **قاعدة البيانات والمصادقة**: PostgreSQL عبر Supabase مع دعم كامل لـ Row Level Security (RLS).
- **التخزين**: Supabase Storage للمرفقات الطبية مع تشفير الوصول وروابط Signed URLs مؤقتة.
- **الاختبارات**: Vitest و Testing Library.

---

## 🚀 طريقة التشغيل محلياً

### 1. تثبيت الحزم والاعتماديات
```bash
npm install
```

### 2. إعداد ملف البيئة
قم بنسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 4. تشغيل الفحوصات والاختبارات
```bash
# فحص الأنواع البرمجية
npm run type-check

# فحص جودة وتنسيق الكود
npm run lint

# تشغيل اختبارات الوحدات
npm run test

# اختبار بناء المشروع للإنتاج
npm run build
```
